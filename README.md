# 🎓 CampusLens AI

**College announcements, made clear.**

CampusLens AI is an open-source student assistant that uses
Gemma 4 to turn lengthy college announcements into clear
summaries, important details, and actionable checklists.

## Features

- Summarizes college announcements in simple English.
- Extracts deadlines and important details.
- Identifies the students or groups affected.
- Generates an actionable checklist.
- Highlights missing or ambiguous information.
- Downloads the analysis as a Markdown file.
- Handles API errors without displaying secret credentials.

## Tech Stack

- Python
- Streamlit
- Google Gen AI Python SDK
- Gemma 4
- python-dotenv
